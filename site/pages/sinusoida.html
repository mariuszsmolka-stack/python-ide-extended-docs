Sinusoida

Sinusoida powtarza swój kształt. Parametry pozwalają zmienić wysokość fali, jej gęstość i przesunięcie.

import ms2d

rysuj(ms2d.sinusoida(A=1, omega=1, faza=0, d=0))

Zmień A na 2. Potem zmień omega na 2. Która zmiana zwiększa wysokość, a która liczbę fal w tym samym przedziale X?

Podgląd przedstawia pierwszy przykład. Przybliżaj i przesuwaj widok. Zmiany wzoru sprawdzaj w edytorze.

AParametry

Wartości domyślne: A=1, omega=1, faza=0, d=0. Wysokość wychylenia od linii środkowej to |A|. Parametr d wyznacza wysokość tej linii. faza przesuwa falę względem osi X.

Dla omega różnego od zera okres wynosi 2π/|omega|. Gdy omega = 0, wynik jest stały. Ujemne A odwraca falę względem linii środkowej.

BWzór i warunki
y=Asin(ωx+φ)+d

W zapisie Python ω to omega, a φ to faza. Kąty podajemy w radianach. Pełny obrót ma 2π radianów.

Dziedzina to wszystkie liczby rzeczywiste. Parametry muszą być skończonymi liczbami int lub float, bez wartości logicznych. Biblioteka dopuszcza także zero i liczby ujemne.

CDefinicja w Pythonie
import math

def f(x, A=1, omega=1, faza=0, d=0):
    return A*math.sin(omega*x + faza) + d

rysuj(f)

Sprawdź wartości dla X = 0 oraz X = π/2. Zapis liczby π w Pythonie to math.pi.

import math

rysuj(lambda x: math.sin(x), lambda x: math.sin(2*x))
