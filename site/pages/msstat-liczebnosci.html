Statystyka

Liczebności

Liczebność mówi, ile razy wystąpiła konkretna wartość. Suma wszystkich liczebności jest równa liczbie danych. Zmieniaj powtórzenia i porównuj udział poszczególnych wartości.

Pierwszy przykład

import msstat

dane = [1, 1, 3, 5, 8]
wynik = msstat.liczebnosci(dane)
print(wynik)

Wynik w konsoli (liczby dziesiętne zaokrąglono w kodzie tam, gdzie użyto round):

[(1.0, 2), (3.0, 1), (5.0, 1), (8.0, 1)]

Eksperymentuj

Dopisz drugą trójkę. Jej liczebność wzrośnie z 1 do 2, a liczebności pozostałych wartości nie zmienią się.

import msstat

dane = [1, 1, 3, 3, 5, 8]
wynik = msstat.liczebnosci(dane)
print(wynik)

Wynik w konsoli (liczby dziesiętne zaokrąglono w kodzie tam, gdzie użyto round):

[(1.0, 2), (3.0, 2), (5.0, 1), (8.0, 1)]

W każdej parze pierwsza liczba jest wartością danych, a druga liczbą jej wystąpień. Suma drugich elementów wszystkich par daje liczbę obserwacji. Nie należy sumować samych różnych wartości zamiast ich liczebności.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Dane podajesz samodzielnie. Pierwszy przykład używa domyślnych wartości pozostałych parametrów.

msstat.liczebnosci(dane)

dane - argument wymagany
Niepusta kolekcja liczb, w której liczone są powtórzenia.

Dane muszą być skończonymi liczbami rzeczywistymi, bez wartości logicznych.

BZnaczenie wyniku i wzór
c(v)=#{i:xi=v}

Wynikiem jest rosnąca lista par (wartość, liczebność). Dane są niepuste i muszą być skończonymi liczbami rzeczywistymi, bez wartości logicznych. Symbol # oznacza liczbę elementów zbioru indeksów.

Dane muszą być skończonymi liczbami rzeczywistymi, bez wartości logicznych. Wynikiem jest lista par uporządkowana rosnąco według wartości, niezależnie od kolejności wejścia.

CZapis obliczenia w Pythonie

from collections import Counter

def oblicz(dane):
    return sorted(Counter(dane).items())

dane = [1, 1, 3, 5, 8]
print(oblicz(dane))
