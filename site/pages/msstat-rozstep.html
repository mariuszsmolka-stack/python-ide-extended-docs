Statystyka

Rozstęp

Rozstęp jest różnicą między największą i najmniejszą wartością. Nie uwzględnia rozmieszczenia pozostałych danych. Porównaj zbiory o tych samych skrajnych wartościach, ale innym środku.

Pierwszy przykład

import msstat

dane = [1, 1, 3, 5, 8]
wynik = msstat.rozstep(dane)
print(round(wynik, 6))

Wynik w konsoli (liczby dziesiętne zaokrąglono w kodzie tam, gdzie użyto round):

7.0

Eksperymentuj

Zastąp 8 przez 50. Rozstęp wzrośnie z 7 do 49, mimo że pozostałe obserwacje nie uległy zmianie.

import msstat

dane = [1, 1, 3, 5, 50]
wynik = msstat.rozstep(dane)
print(round(wynik, 6))

Wynik w konsoli (liczby dziesiętne zaokrąglono w kodzie tam, gdzie użyto round):

49.0

Rozstęp mierzy pełną szerokość danych, a nie ich typowe skupienie. Dwa zbiory o takich samych skrajnych wartościach mogą mieć zupełnie inne rozmieszczenie pozostałych liczb.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Dane podajesz samodzielnie. Pierwszy przykład używa domyślnych wartości pozostałych parametrów.

msstat.rozstep(dane)

dane - argument wymagany
Niepusta kolekcja liczb, z której wybierane są minimum i maksimum.

Dane muszą być skończonymi liczbami rzeczywistymi, bez wartości logicznych.

BZnaczenie wyniku i wzór
R=max(xi)-min(xi)

Dane muszą być niepuste. Rozstęp jest nieujemny i wynosi zero wtedy, gdy wszystkie wartości są jednakowe. Pojedyncza skrajna obserwacja może go znacznie zwiększyć.

Potrzebne są skończone liczby rzeczywiste, bez wartości logicznych. Dla jednej obserwacji i dla zbioru jednakowych wartości wynik wynosi zero.

CZapis obliczenia w Pythonie

def oblicz(dane):
    return max(dane) - min(dane)

dane = [1, 1, 3, 5, 8]
print(oblicz(dane))
