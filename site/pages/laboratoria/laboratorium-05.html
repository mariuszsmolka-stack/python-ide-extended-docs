Laboratoria / Eksperyment 05

Czy można wylosować liczbę π?

Wyobraź sobie kwadrat o boku 1. W jego rogu znajduje się ćwiartka koła o promieniu 1.

Czy takie losowanie pozwoli nam przybliżyć liczbę π?

Na jaki obszar losujemy punkty?

Losujemy punkt w kwadracie. Za trafienie uznajemy punkt należący do zacieniowanej ćwiartki koła, również do jej brzegu. Udział trafień wykorzystujemy do oszacowania liczby π.

W kolejnej wersji dodamy „strzelanie do tarczy”. :)

Dla punktu o współrzędnych od 0 do 1 sprawdzamy warunek x*x + y*y <= 1. Mówi on, czy punkt należy do ćwiartki koła, łącznie z jej brzegiem.

Przykład 1 - trafienie. Dla x = 0.3, y = 0.4 obliczamy 0,3² + 0,4² = 0,25. Ponieważ 0,25 ≤ 1, punkt należy do ćwiartki koła.

Przykład 2 - brak trafienia. Dla x = 0.9, y = 0.7 obliczamy 0,9² + 0,7² = 1,30. Ponieważ 1,30 > 1, punkt znajduje się poza ćwiartką koła.

2. Program Python

Liczba startowa generatora liczb pseudolosowych to ziarno. W random.Random(2026) tą liczbą jest 2026. To samo ziarno pozwala powtórzyć identyczne losowanie. Zmiana na random.Random(9) daje inną sekwencję liczb. Każda współrzędna punktu pochodzi z przedziału od 0 do 1, bez prawego końca.

Skopiuj cały program do Python IDE Extended i wybierz Uruchom. Pętla kontynuuje jeden eksperyment. Wynik po 100 próbach dotyczy pierwszych 100 punktów, a nie osobnego losowania.

import random

losuj = random.Random(2026)
trafienia = 0

for n in range(1, 10001):
    x = losuj.random()
    y = losuj.random()

    if x*x + y*y <= 1:
        trafienia += 1

    if n in (100, 1000, 10000):
        pi = 4 * trafienia / n
        print(n, trafienia, round(pi, 4))

Pobierz program .py. Jak uruchomić program w IDE?

Trzy liczby w każdym wierszu konsoli to: liczba prób, liczba trafień i przybliżenie π. round(pi, 4) zaokrągla jedynie wyświetlany wynik do czterech miejsc po przecinku.

4. Obserwacje i wnioski

Dlaczego mnożymy przez 4?

Pole kwadratu o boku 1 wynosi 1. Pole ćwiartki koła o promieniu 1 wynosi π/4. W dużej próbie niezależnych, równomiernych losowań udział trafień powinien być bliski udziałowi tego pola w polu kwadratu.

π≈4×trafienialiczba prób

Nie obliczyliśmy pola koła bezpośrednio. Oszacowaliśmy je, licząc losowe trafienia. Skończona próba daje przybliżenie, które zależy od losowania.

Jak porównać dokładność?

Błąd bezwzględny to odległość przybliżenia od wartości odniesienia. Mniejszy błąd oznacza dokładniejszy wynik. W Pythonie zapisujemy blad = abs(wynik - math.pi), po import math. Używamy math.pi wyłącznie do porównania, nie do wyznaczania oszacowania.

Drugie doświadczenie: ziarno 9

W wierszu losuj = random.Random(2026) zamień 2026 na 9 i ponownie uruchom program. Porównaj błędy po 1000 i 10 000 próbach. Poniżej jest kompletny wariant wypisujący również błąd.

Kod doświadczenia z porównaniem błędów
import random
import math

losuj = random.Random(9)
trafienia = 0

for n in range(1, 10001):
    x = losuj.random()
    y = losuj.random()

    if x*x + y*y <= 1:
        trafienia += 1

    if n in (100, 1000, 10000):
        pi = 4 * trafienia / n
        blad = abs(pi - math.pi)
        print(n, trafienia, round(pi, 4), round(blad, 6))

Więcej prób zwykle poprawia dokładność statystyczną oszacowania, ale nie gwarantuje, że każdy kolejny wynik będzie bliższy π. Ogranicza typową skalę przypadkowych wahań, a nie usuwa ich z każdego doświadczenia.

Pytania do obserwacji

  1. Czy w losowaniu narzuciliśmy regularne rozmieszczenie punktów?
  2. Czy 100 punktów może dać rozsądne przybliżenie π?
  3. Co zmienia się po zwiększeniu liczby punktów?
  4. Czy 10 000 losowań zawsze da dokładniejszy wynik niż 1000?
  5. Dlaczego mnożymy udział trafień przez 4?
Sprawdź odpowiedzi na pytania
  1. Nie. Obie współrzędne wybiera generator; nie układamy punktów w regularnych odstępach.
  2. Może, ale mała próba daje duże wahania. Dla ziarna 2026 otrzymaliśmy 3,08, a dla ziarna 9 wynik 3,4.
  3. W większych próbach zwykle zmniejsza się skala przypadkowych wahań udziału trafień.
  4. Nie. W doświadczeniu z ziarnem 9 wynik po 1000 próbach jest dokładniejszy niż po 10 000.
  5. Ćwiartka koła zajmuje część π/4 pola kwadratu. Mnożenie udziału trafień przez 4 daje oszacowanie π.
