Funkcja stała

Wykresem jest pozioma prosta, ponieważ wynik nie zależy od X. Parametr c określa jej wysokość. Porównaj wykresy dla dodatniego i ujemnego c.

Pierwszy przykład

import ms2d

f = ms2d.stala()
print(round(f(0), 6))
rysuj(f)

Wynik w konsoli:

2.0

Wynik f w podanym argumencie jest współrzędną Y punktu wykresu. W podglądzie są tylko wartości obliczone w ograniczonym przedziale X.

Podgląd przedstawia pierwszy program. Zmianę kodu wykonaj w edytorze. Przesuwanie i przybliżanie nie obliczają nowych wartości funkcji.

Eksperymentuj

Zastąp domyślne c=2 przez c=-2. Obie proste mają to samo nachylenie, ale leżą po przeciwnych stronach osi X.

import ms2d

f = ms2d.stala(c=-2)
print(round(f(0), 6))
rysuj(f)

Wynik w konsoli:

-2.0

Wartości f(0), f(3) i f(-3) są jednakowe. Dla c=0 wykres pokrywa się z osią X, więc każdy argument jest miejscem zerowym.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Pierwszy program wywołuje funkcję bez ustawień, czyli korzysta z wszystkich wartości domyślnych podanych poniżej.

ms2d.stala(c=2)

c=2
Wysokość poziomej prostej.

Parametry liczbowe muszą być skończonymi liczbami int lub float, bez wartości logicznych.

BRównanie, właściwości i dziedzina
y=c

Dziedziną są wszystkie liczby rzeczywiste. Dla c = 0 cała oś X jest wykresem, a dla c różnego od zera funkcja nie ma miejsc zerowych.

Każdy rzeczywisty X jest dozwolony. Parametr c jest skończoną liczbą; nie ma warunku dodatniości.
