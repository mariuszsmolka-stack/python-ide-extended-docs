Statystyka

Odchylenie standardowe

Odchylenie standardowe jest miarą rozrzutu wyrażoną w tych samych jednostkach co dane. Wynosi zero dla jednakowych wartości. Porównaj zbiory skupione blisko średniej i mocno rozproszone.

Pierwszy przykład

import msstat

dane = [1, 1, 3, 5, 8]
wynik = msstat.odchylenie_standardowe(dane)
print(round(wynik, 6))

Wynik w konsoli (liczby dziesiętne zaokrąglono w kodzie tam, gdzie użyto round):

2.6533

Eksperymentuj

Zmień proba=False na proba=True bez zmiany danych. Porównaj wynik z pierwiastkiem z odpowiedniej wariancji.

import msstat

dane = [1, 1, 3, 5, 8]
wynik = msstat.odchylenie_standardowe(dane, proba=True)
print(round(wynik, 6))

Wynik w konsoli (liczby dziesiętne zaokrąglono w kodzie tam, gdzie użyto round):

2.966479

Odchylenie standardowe ma tę samą jednostkę co dane, np. centymetry zamiast centymetrów kwadratowych. Dla początkowego zbioru wynosi około 2.6533. Nie jest to średnia odległość od średniej, lecz pierwiastek ze średniego kwadratu odchyleń przy wybranym mianowniku.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Dane podajesz samodzielnie. Pierwszy przykład używa domyślnych wartości pozostałych parametrów.

msstat.odchylenie_standardowe(dane, proba=False)

dane - argument wymagany
Niepusta kolekcja danych.
proba=False
False wybiera populację, a True próbę i wymaga co najmniej dwóch obserwacji.

Dane muszą być skończonymi liczbami rzeczywistymi, bez wartości logicznych.

BZnaczenie wyniku i wzór
s=V

Jest to pierwiastek z wariancji V. Parametr proba wybiera ten sam mianownik co przy wariancji: n dla populacji lub n-1 dla próby, która wymaga n ≥ 2. Dane muszą być niepuste.

Dane muszą być rzeczywiste i skończone, bez wartości logicznych. Parametr proba jest wartością logiczną. Dla proba=True potrzebne są co najmniej dwie obserwacje.

CZapis obliczenia w Pythonie
import msstat
import math


def oblicz(dane, proba=False):
    return math.sqrt(msstat.wariancja(dane, proba=proba))

dane = [1, 1, 3, 5, 8]
print(oblicz(dane))
