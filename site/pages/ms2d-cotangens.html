Cotangens

Przy domyślnych parametrach wykres ma powtarzające się, opadające gałęzie. Przerwy występują tam, gdzie sinus kąta jest równy zero. Zmieniając fazę, porównaj położenie gałęzi.

Pierwszy przykład

import ms2d
import math

f = ms2d.cotangens()
print(round(f(math.pi/4), 6))
rysuj(f)

Wynik w konsoli:

1.0

Wynik f w podanym argumencie jest współrzędną Y punktu wykresu. W podglądzie są tylko wartości obliczone w ograniczonym przedziale X.

Podgląd przedstawia pierwszy program. Zmianę kodu wykonaj w edytorze. Przesuwanie i przybliżanie nie obliczają nowych wartości funkcji.

Eksperymentuj

Zmień fazę z 0 na π/4. Dla omega=1 wykres przesunie się w lewo o π/4, a X=0 przestanie być niedozwolonym argumentem.

import ms2d
import math

f = ms2d.cotangens(faza=math.pi/4)
print(round(f(math.pi/4), 6))
rysuj(f)

Wynik w konsoli:

0.0

Cotangens jest ilorazem cosinusa i sinusa tego samego kąta. Przy zerowym sinusie iloraz nie istnieje. Dla niezerowych A i omega asymptoty oddzielają gałęzie, które przy dodatnim A·omega są malejące.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Pierwszy program wywołuje funkcję bez ustawień, czyli korzysta z wszystkich wartości domyślnych podanych poniżej.

ms2d.cotangens(A=1, omega=1, faza=0, d=0)

A=1
Skala wartości; ujemna odwraca kierunek gałęzi.
omega=1
Zmiana kąta na jednostkę X; określa odstępy między gałęziami.
faza=0
Przesunięcie kąta, w radianach.
d=0
Przesunięcie pionowe.

Parametry liczbowe muszą być skończonymi liczbami int lub float, bez wartości logicznych.

BRównanie, właściwości i dziedzina
ctg(α)=cos(α)sin(α)α=ωx+φ,y=Actg(α)+dx=jπ-φω

We wzorze ω oznacza omega, φ oznacza faza, a α jest kątem w radianach; wymagane jest sin(α) ≠ 0. Dla niezerowych A i omega proste wyznaczone przez α = jπ są pionowymi asymptotami: gałęzie zbliżają się do nich, lecz ich nie przecinają; j jest całkowite. Okres wynosi π/|omega|, a d przesuwa wykres pionowo. Przy dodatnim A·omega tangens rośnie, a cotangens maleje; ujemny iloczyn odwraca kierunek. Dla A = 0 wartości są stałe, ale wykluczenia pozostają. Dla omega = 0 otrzymujemy stałą tylko dla dozwolonego kąta.

Wykluczone są argumenty, dla których sin(omega*x+faza)=0. Przy omega=0 wynik istnieje tylko dla dozwolonej fazy. Parametry są skończone.

CDefinicja w Pythonie
import math

def f(x, A=1, omega=1, faza=0, d=0):
    kat = omega * x + faza
    if math.remainder(kat, math.pi) == 0:
        raise ValueError('Niedozwolony kąt')
    return A * (math.cos(kat) / math.sin(kat)) + d

print(round(f(math.pi/4), 6))
rysuj(f)
