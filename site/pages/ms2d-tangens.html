Matematyka 2D

Tangens

Przy domyślnych parametrach wykres ma powtarzające się, rosnące gałęzie. Przerwy występują tam, gdzie cosinus kąta jest równy zero. Zmieniając omega, porównaj odstępy między gałęziami.

Pierwszy przykład

import ms2d

f = ms2d.tangens()
print(round(f(0), 6))
rysuj(f)

Wynik w konsoli:

0.0

Wynik f w podanym argumencie jest współrzędną Y punktu wykresu. W podglądzie są tylko wartości obliczone w ograniczonym przedziale X.

Podgląd przedstawia pierwszy program. Zmianę kodu wykonaj w edytorze. Przesuwanie i przybliżanie nie obliczają nowych wartości funkcji.

Eksperymentuj

Zmień omega z 1 na 2. Dla niezerowego A okres zmaleje z π do π/2, więc w tym samym przedziale pojawi się więcej gałęzi.

import ms2d

f = ms2d.tangens(omega=2)
print(round(f(0), 6))
rysuj(f)

Wynik w konsoli:

0.0

Tangens to iloraz sinusa i cosinusa tego samego kąta. Gdy mianownik zbliża się do zera, powstają osobne gałęzie ograniczone pionowymi asymptotami. Dla dodatniego A·omega każda gałąź rośnie.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Pierwszy program wywołuje funkcję bez ustawień, czyli korzysta z wszystkich wartości domyślnych podanych poniżej.

ms2d.tangens(A=1, omega=1, faza=0, d=0)

A=1
Skala wartości; ujemna odwraca kierunek gałęzi.
omega=1
Zmiana kąta na jednostkę X; określa odstępy między gałęziami.
faza=0
Przesunięcie kąta, w radianach.
d=0
Przesunięcie wykresu w pionie.

Parametry liczbowe muszą być skończonymi liczbami int lub float, bez wartości logicznych.

BRównanie, właściwości i dziedzina
tg(α)=sin(α)cos(α)α=ωx+φ,y=Atg(α)+dx=π2+jπ-φω

We wzorze ω oznacza omega, φ oznacza faza, a α jest kątem w radianach; wymagane jest cos(α) ≠ 0. Dla niezerowych A i omega proste wyznaczone przez α = π/2 + jπ są pionowymi asymptotami: gałęzie zbliżają się do nich, lecz ich nie przecinają; j jest całkowite. Okres wynosi π/|omega|, a d przesuwa wykres pionowo. Przy dodatnim A·omega tangens rośnie, a cotangens maleje; ujemny iloczyn odwraca kierunek. Dla A = 0 wartości są stałe, ale wykluczenia pozostają. Dla omega = 0 otrzymujemy stałą tylko dla dozwolonego kąta.

Wykluczone są argumenty, dla których cos(omega*x+faza)=0. Dla omega=0 dozwolona faza daje stałą, a niedozwolona nie daje żadnych wartości. Parametry są skończone.

CDefinicja w Pythonie
import math

def f(x, A=1, omega=1, faza=0, d=0):
    kat = omega * x + faza
    if abs(math.remainder(kat, math.pi)) == math.pi / 2:
        raise ValueError('Niedozwolony kąt')
    return A * math.tan(kat) + d

print(round(f(0), 6))
rysuj(f)

Spróbuj sam

Ustaw faza=π/4. Wyznacz najbliższą zeru pionową asymptotę, uwzględniając przekształcenie argumentu.
