Funkcja sinc

Wykres jest symetryczny względem osi Y i ma w środku wartość 1. Kolejne oscylacje, czyli powtarzające się wychylenia, stają się coraz mniejsze. Porównaj wartości w równych odległościach po obu stronach zera.

Pierwszy przykład

import ms2d

f = ms2d.sinc()
print(round(f(0), 6))
rysuj(f)

Wynik w konsoli:

1.0

Wynik f w podanym argumencie jest współrzędną Y punktu wykresu. W podglądzie są tylko wartości obliczone w ograniczonym przedziale X.

Podgląd przedstawia pierwszy program. Zmianę kodu wykonaj w edytorze. Przesuwanie i przybliżanie nie obliczają nowych wartości funkcji.

Eksperymentuj

Ta funkcja nie przyjmuje ustawień. Zamiast nich porównaj wartości dla X=0, X=π i X=2π oraz zachowanie po obu stronach zera.

import math
import ms2d

f = ms2d.sinc()
for x in [0, math.pi, 2*math.pi]:
    print(f(x))
rysuj(f)

Wynik w konsoli:

1.0
3.8981718325193755e-17
-3.8981718325193755e-17

Nie należy traktować zera jako przerwy. Wartość w środku została określona tak, aby krzywa była ciągła. W punktach będących wielokrotnościami π komputer może otrzymać bardzo małą liczbę zamiast dokładnego zera.

AParametry i wartości domyślne

Pierwszy program wywołuje funkcję bez ustawień, czyli korzysta z wszystkich wartości domyślnych podanych poniżej.

ms2d.sinc()

Ta funkcja nie przyjmuje parametrów. Nie dopisuj do wywołania dodatkowych argumentów.

BRównanie, właściwości i dziedzina

Dziedziną są wszystkie liczby rzeczywiste: w zerze przyjęto wartość graniczną 1. Pozostałe miejsca zerowe to niezerowe całkowite wielokrotności π. Funkcja nie ma parametrów.

Dziedziną są wszystkie liczby rzeczywiste. Funkcja nie ma parametrów; w zerze przyjmuje osobno wartość 1, równą granicy sin(x)/x.

CDefinicja w Pythonie
import math

def f(x):
    return 1.0 if x == 0 else math.sin(x) / x

print(round(f(0), 6))
rysuj(f)
DKrótki zapis lambda

Wartość w zerze wynosi 1; dla pozostałych argumentów dzielimy sinus przez argument.

import math

rysuj(lambda x: 1.0 if x == 0 else math.sin(x) / x)
