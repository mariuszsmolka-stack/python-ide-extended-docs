Prosta pionowa

Każdy punkt tej prostej ma tę samą współrzędną X. Nie jest to wykres pojedynczej wartości Y dla każdego X. Zmieniaj c, aby przesuwać prostą poziomo.

Pierwszy przykład

import ms2d

F = ms2d.prosta_pionowa()
print(round(F(2, 0), 6))
rysuj_2(F)

Wynik w konsoli:

0.0

Wartość F w podanym punkcie jest liczbą pomocniczą, a nie współrzędną Y. Do krzywej należą punkty z wynikiem zero. Dziedzina F obejmuje więcej punktów niż sama krzywa.

Podgląd przedstawia pierwszy program. Zmianę kodu wykonaj w edytorze. Przesuwanie i przybliżanie nie obliczają nowych wartości funkcji.

Eksperymentuj

Zmień c z 2 na -2. Pionowa prosta przesunie się na drugą stronę osi Y, bez zmiany kierunku.

import ms2d

F = ms2d.prosta_pionowa(c=-2)
print(round(F(2, 0), 6))
rysuj_2(F)

Wynik w konsoli:

4.0

Do jednej wartości X należy nieskończenie wiele wartości Y. Dlatego nie zapisujemy tej prostej jako y=f(x). Funkcja pomocnicza F(x,y)=x-c pozwala opisać ją równaniem.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Pierwszy program wywołuje funkcję bez ustawień, czyli korzysta z wszystkich wartości domyślnych podanych poniżej.

ms2d.prosta_pionowa(c=2)

c=2
Stała współrzędna X prostej.

Parametry liczbowe muszą być skończonymi liczbami int lub float, bez wartości logicznych.

BRównanie, właściwości i dziedzina
x=c

Równanie określa prostą pionową, a parametr c jej położenie. Funkcja pomocnicza F jest określona dla każdej pary liczb rzeczywistych; jej poziom zero spełnia poniższe równanie.

Funkcja F jest określona dla każdej pary rzeczywistych współrzędnych. Parametr c jest skończony. Krzywa składa się tylko z punktów, dla których F=0.

CDefinicja w Pythonie

def F(x, y, c=2):
    return x - c

print(round(F(2, 0), 6))
rysuj_2(F)
DKrótki zapis lambda

Ten zapis dotyczy domyślnych parametrów.

rysuj_2(lambda x, y: x - 2)

Spróbuj sam

Narysuj wspólnie pionową prostą i okrąg. Dobierz c tak, aby wystąpiły dwa, jeden albo żaden punkt wspólny.
