Paraboloida hiperboliczna

Powierzchnia wygina się w górę w jednym kierunku i w dół w drugim. Punkt środkowy nie jest ani minimum, ani maksimum. Zmieniaj a i b, aby porównać oba wygięcia.

Pierwszy przykład

import ms3d

F = ms3d.paraboloida_hiperboliczna()
print(round(F(0, 0, 0), 6))
rysuj_3(F)

Wynik w konsoli:

0.0

Wartość F w podanym punkcie nie jest wysokością powierzchni. Narysowane są punkty F=0, bez wypełniania wnętrza bryły. Matematyczna powierzchnia i obszar podglądu to różne rzeczy.

Podgląd przedstawia pierwszy program. Zmianę kodu wykonaj w edytorze. Obrót, przesuwanie i przybliżanie nie obliczają nowych wartości funkcji.

Eksperymentuj

Zmniejsz b z 3 do 1.5. Przekrój w kierunku Y będzie opadał szybciej, podczas gdy przekrój Y=0 pozostanie bez zmian.

import ms3d

F = ms3d.paraboloida_hiperboliczna(b=1.5)
print(round(F(0, 0, 0), 6))
rysuj_3(F)

Wynik w konsoli:

0.0

W początku układu można zwiększyć wysokość, idąc wzdłuż X, albo ją zmniejszyć, idąc wzdłuż Y. Punkt ten jest siodłowy: nie jest ani lokalnym minimum, ani maksimum.

Odkrywaj w swoim tempie

AParametry i wartości domyślne

Pierwszy program wywołuje funkcję bez ustawień, czyli korzysta z wszystkich wartości domyślnych podanych poniżej.

ms3d.paraboloida_hiperboliczna(a=3, b=3)

a=3
Dodatnia skala w kierunku X.
b=3
Dodatnia skala w kierunku Y.

Parametry liczbowe muszą być skończonymi liczbami int lub float, bez wartości logicznych.

BRównanie, właściwości i dziedzina
z=(xa)2-(yb)2

Wymagane jest a, b > 0, a wysokość istnieje dla dowolnych x i y. Przekroje X = 0 i Y = 0 są parabolami skierowanymi przeciwnie. W początku układu leży punkt siodłowy.

Parametry a i b są dodatnie. Wysokość jest określona dla każdej pary X,Y, a F dla każdej trójki współrzędnych. Powierzchnia nie jest granicą zamkniętej bryły.

CDefinicja w Pythonie

def F(x, y, z, a=3, b=3):
    return z - (x / a) ** 2 + (y / b) ** 2

print(round(F(0, 0, 0), 6))
rysuj_3(F)
DKrótki zapis lambda

Ten zapis dotyczy domyślnych parametrów.

rysuj_3(lambda x, y, z: z - (x / 3) ** 2 + (y / 3) ** 2)
