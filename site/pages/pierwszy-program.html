Pierwszy program w IDE

Program to lista poleceń. Python wykonuje je po kolei. Zacznij od wyświetlenia krótkiej wiadomości.

Najpierw uruchom

imie = "Ola"
print("Cześć,", imie)
print("2 + 3 =", 2 + 3)

Skopiuj kod. Otwórz edytor, wklej program i wybierz Uruchom. Wynik pojawi się w konsoli, czyli dolnym panelu na wyniki programu.

Zmień imię i liczby. Czy tekst "2 + 3 =" zmieni się sam, gdy zmienisz obliczenie?

Odkrywaj w swoim tempie

ATekst, liczba i nazwa

Cudzysłowy oznaczają tekst. Zapis 2 + 3 bez cudzysłowów oznacza obliczenie. Nazwa imie pozwala wrócić do zapisanej wartości.

Znak = przypisuje wartość do nazwy. Nie jest tu pytaniem o równość.

BZapytaj użytkownika
imie = input("Jak masz na imię? ")
print("Cześć,", imie)

Program czeka na odpowiedź w polu pod edytorem. Wpisz ją i naciśnij Enter albo Wyślij. input() zwraca tekst.

CNapisz własną funkcję
def przywitaj(imie="Ola"):
    return "Cześć, " + imie

print(przywitaj())
print(przywitaj("Jan"))

Parametr imie przyjmuje przekazany tekst. Wartość domyślna to "Ola". return zwraca wynik. Wcięcie wskazuje polecenie należące do funkcji.

Co pojawi się po wywołaniu przywitaj("Ada")? Ta funkcja jest przykładem napisanym tutaj, a nie częścią bibliotek matematycznych.

To krótki start w środowisku, nie cały kurs Pythona. W kolejnych artykułach użyjesz funkcji do doświadczeń matematycznych.
